# Coffee-House: Business Functionality

## ☕ Project Overview

Coffee-House is an e-commerce website for a coffee shop where users can browse products, view product details, and explore featured items on a slider. The project is built with TypeScript, Vite, and vanilla JS/TS.

## 📝 Notes for Reviewers

- For product cards, I used the global `discountedPrice` from the product object, while for modals I used `discountedPrice` from the sizes and additives objects.
- The slider uses placeholder images when product data is not available.
- All code is linted and follows consistent formatting.

## 🛠 Technologies

- TypeScript
- Vite
- HTML & CSS
- Vanilla JS
- ESLint

## 📦 Installation

```bash
# Clone repo
git clone https://github.com/levansarishvili/coffee-house

# Go to project folder
cd coffee-house

# Go to project branch
git checkout coffee-house-ts

# Go to coffee-house folder
cd coffee-house

# Install dependencies
npm install

# Run development server
npm run dev

# Run eslint to check errors
npm run lint

```
